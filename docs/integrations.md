# Integrações

## Atlas

- Catálogo: `organizations/moratta/developments` e `properties`.
- Leads do site: `organizations/moratta/leads`.
- Origem: `site`.
- Etapa inicial: `new`.
- UTMs e identificação do empreendimento são gravadas no lead.

## Meta Ads

As páginas preservam parâmetros `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`, `campaign`, `adset` e `ad` no formulário de interesse.

## WhatsApp

Nesta versão, o WhatsApp usa links diretos. API oficial e histórico de conversas entram em uma etapa posterior.
